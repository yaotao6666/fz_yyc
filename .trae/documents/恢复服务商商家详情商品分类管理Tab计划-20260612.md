# 恢复服务商商家详情商品/分类管理 Tab 计划

## Summary

修复 `web-admin` 服务商 PC 后台中“商家详情”页面丢失的 `商品管理`、`分类管理` 两个 Tab 及其操作能力。

本次方案以当前已存在的服务商代理后端接口为基础，在 `web-admin` 商家详情页内恢复三段式结构：

1. `基础资料`：保留当前详情页已有的商家资料、二维码、图片资产能力。
2. `商品管理`：恢复商品列表筛选、批量上下架、新增/编辑/删除、库存维护。
3. `分类管理`：恢复分类列表、新增/编辑/删除、状态维护、排序维护。

同时，本次计划包含 `web-admin/sp` 构建产物重建与替换，避免源码已修但部署页面仍是旧包。

## Current State Analysis

### 1. 当前商家详情页源码已不含商品/分类 Tab

- 当前 `web-admin` 商家详情页只保留了概览卡片、商家资料、图片资产：
  - [MerchantDetailView.vue](file:///e:/yt/fz_yyc/web-admin/src/views/merchant/MerchantDetailView.vue)
- 该文件内没有 `ElTabs`、商品列表、分类列表或相关 CRUD 逻辑。
- 用户截图中的 `基础资料 / 商品管理 / 分类管理` 结构，与当前源码不一致，说明这部分功能在迁移/重构时被移除了。

  - 商品：
    - `GET /api/v1/sp/merchants/:merchant_id/products`
    - `GET /api/v1/sp/merchants/:merchant_id/products/:product_id`
    - `POST /api/v1/sp/merchants/:merchant_id/products`
    - `PUT /api/v1/sp/merchants/:merchant_id/products/:product_id`
    - `POST /api/v1/sp/merchants/:merchant_id/products/:product_id/on-sale`
    - `POST /api/v1/sp/merchants/:merchant_id/products/:product_id/off-sale`

- 这说明“服务商无法使用”的核心问题，当前落在 `web-admin` 页面层能力缺失，而不是后端路由不存在。

## Proposed Changes

### A. 为 `web-admin` 增加商品/分类/规格的 SP API 封装

#### 文件

- `web-admin/src/api/sp.ts`

#### 修改内容

- 新增分类相关方法：
  - `getMerchantCategories(merchantId)`
  - `createMerchantCategory(merchantId, payload)`
  - `updateMerchantCategory(merchantId, categoryId, payload)`
  - `deleteMerchantCategory(merchantId, categoryId)`
  - `sortMerchantCategories(merchantId, categories)`
- 新增商品相关方法：
  - `getMerchantProducts(merchantId, params)`
  - `getMerchantProduct(merchantId, productId)`
  - `createMerchantProduct(merchantId, payload)`
  - `updateMerchantProduct(merchantId, productId, payload)`
  - `merchantProductOnSale(merchantId, productId)`
  - `merchantProductOffSale(merchantId, productId)`
  - `batchUpdateMerchantProductStatus(merchantId, productIds, status)`
  - `deleteMerchantProduct(merchantId, productId)`
  - `updateMerchantProductStock(merchantId, productId, stock)`
- 新增规格相关方法：
  - `getMerchantProductSpecs(merchantId, productId)`
  - `updateMerchantProductSpecs(merchantId, productId, payload)`

#### 目的

- 统一让 PC 服务商后台只调用 `/api/v1/sp/merchants/:merchant_id/...`。
- 不再在 `web-admin` 中混用商家接口和服务商接口。

### B. 为 `web-admin` 补齐商品/分类相关类型定义

#### 文件

- `web-admin/src/types/sp.ts`

#### 修改内容

- 新增分类类型：
  - `MerchantCategory`
  - `MerchantCategoryPayload`
- 新增商品类型：
  - `MerchantProduct`
  - `MerchantProductListResponse`
  - `MerchantProductUpsertPayload`
  - `MerchantProductSpec`
  - `MerchantProductSpecOption`
  - `MerchantProductSpecUpdatePayload`
- 字段与后端商家接口返回结构对齐，优先参考：

  - [product_specs_endpoints.go](file:///e:/yt/fz_yyc/server/internal/handlers/merchant/product_specs_endpoints.go)

#### 目的

- 避免 `MerchantDetailView.vue` 内联 `any` 结构。
- 让商品管理和分类管理的表格、弹窗、校验都能用强类型实现。

### C. 在商家详情页恢复 Tab 化结构

#### 文件

- `web-admin/src/views/merchant/MerchantDetailView.vue`

#### 修改内容

- 将当前“平铺详情页”改成 `el-tabs` 结构：
  - `基础资料`
  - `商品管理`
  - `分类管理`
- `基础资料` Tab 内保留当前已有内容：
  - 商家状态、支付配置、用户数、累计金额
  - 商家资料区
  - 图片资产区
  - 二维码查看
  - 自提点管理按钮
- `商品管理`、`分类管理` 通过子组件承载，避免把全部逻辑堆到详情页里。

#### 目的

- 直接恢复用户截图中的交互心智。
- 保留当前详情页已完成的资料、图片、自提点入口能力。

### D. 新增“商品管理”子组件，恢复商品 Tab 的完整能力

#### 文件

- 新增 `web-admin/src/views/merchant/components/MerchantProductsTab.vue`
- 新增 `web-admin/src/views/merchant/components/MerchantProductEditorDialog.vue`

#### 修改内容

- `MerchantProductsTab.vue` 负责：
  - 加载商品列表
  - 筛选项：分类、状态、关键词
  - 表格列：图片、商品名称、分类、售价、库存、销量、状态、商品摘要、操作
  - 行选择 + 批量上架 / 批量下架
  - 行操作：编辑、上架/下架、删除、快速改库存
  - “新增商品”按钮
- `MerchantProductEditorDialog.vue` 负责：
  - 新增/编辑商品表单
  - 字段：名称、分类、描述、售价、原价、库存、单位、图片、排序、状态
  - 规格编辑：规格名 + 选项列表（与后端规格接口对齐）
  - 商品图片上传复用：
    - [qiniu.ts](file:///e:/yt/fz_yyc/web-admin/src/utils/qiniu.ts)

#### 关键实现决策

- 商品新增/编辑采用 `ElDialog` 或 `ElDrawer` 的单页表单模式，不新增独立路由。
- 保存时：
  - 先调用商品创建/更新接口；
  - 如果规格区被编辑，则再调用规格保存接口，保证与现有后端接口形态一致。
- 商品详情回填时：
  - 通过 `getMerchantProduct` 获取商品主体；
  - 如需独立规格结构，则补调用 `getMerchantProductSpecs`。

#### 目的

- 在保持“商家详情页内管理”的前提下，恢复截图中的商品管理能力。
- 避免扩散到新的路由体系，减少改造面。

### E. 新增“分类管理”子组件，恢复分类 Tab 的完整能力

#### 文件

- 新增 `web-admin/src/views/merchant/components/MerchantCategoriesTab.vue`

#### 修改内容

- 展示分类列表：
  - 分类名称
  - 商品数
  - 排序
  - 状态
  - 创建时间
  - 操作
- 支持操作：
  - 新增分类
  - 编辑分类
  - 删除分类
  - 启用/停用分类
  - 调整排序并保存

#### 关键实现决策

- 分类的新增/编辑采用弹窗表单。
- 排序采用表格内数字输入 + 单次“保存排序”按钮，直接调用 `sortMerchantCategories`。
- 状态变更复用 `updateMerchantCategory`，避免引入单独状态接口。

#### 目的

- 恢复原详情页中的分类管理能力。
- 让服务商能直接代理维护商家分类，而不需要切回小程序商家端。

## Assumptions & Decisions

- 已确认本次目标不是新增独立“商品管理页面”，而是恢复 `商家详情` 内原有的 `商品管理 / 分类管理` Tab。
