# 用户行为埋点与分析实施计划

## 📋 需求概述

### 功能目标
1. **用户访问埋点**：用户扫码进入商家主页时，自动记录访问事件
2. **用户数量统计**：按 OpenID 去重，统计每个商家的用户数量
3. **支付状态追踪**：记录用户是否支付、累计支付次数
4. **服务商数据看板**：服务商管理端能看到所有商家的用户分析数据

### 核心业务逻辑
- **用户唯一标识**：通过微信 OpenID 作为唯一标识
- **访问事件记录**：用户在商家主页访问时记录埋点数据
- **去重统计**：同一用户多次访问只算一个用户
- **支付追踪**：记录用户的支付状态和累计支付次数
- **服务商视角**：服务商可查看所有商家的用户分析数据

### 阶段2：后端接口开发

#### 2.1 用户访问埋点接口
**文件**：`server/internal/handlers/user/handler.go`

**功能**：
- 记录用户访问商家主页事件
- 更新用户访问统计（首次访问时间、最后访问时间、访问次数）
- 按 OpenID 自动创建或更新用户记录

**代码实现**：
```go
func RecordUserVisit(c *gin.Context) {
    merchantID := c.Param("merchant_id")
    mid, _ := strconv.ParseUint(merchantID, 10, 64)

    var req struct {
        OpenID  string `json:"openid"`
        Source  string `json:"source"` // 来源
    }
    c.ShouldBindJSON(&req)

    if req.OpenID == "" {
        response.Fail(c, http.StatusBadRequest, response.CodeParamError, "缺少openid")
        return
    }

    var user models.User
    result := database.DB.Where("openid = ?", req.OpenID).First(&user)

    now := time.Now()

    if result.Error == gorm.ErrRecordNotFound {
        // 首次访问，创建用户记录
        user = models.User{
            OpenID:        req.OpenID,
            Nickname:      "微信用户",
            Status:        1,
            FirstVisitAt:  &now,
            LastVisitAt:   &now,
            VisitCount:    1,
        }
        database.DB.Create(&user)
    } else {
        // 更新访问统计
        updates := map[string]interface{}{
            "last_visit_at": now,
            "visit_count":   gorm.Expr("visit_count + 1"),
        }
        // 如果之前没有访问过，设置首次访问时间
        if user.FirstVisitAt == nil {
            updates["first_visit_at"] = now
        }
        database.DB.Model(&user).Updates(updates)
    }

    // 可选：记录访问明细
    visit := models.UserVisit{
        UserID:     user.ID,
        MerchantID: mid,
        OpenID:     req.OpenID,
        VisitTime:  now,
        Source:     req.Source,
    }
    database.DB.Create(&visit)

    response.Success(c, gin.H{
        "user_id":    user.ID,
        "visit_count": user.VisitCount,
    })
}
```

```go
func GetMerchantUserStats(c *gin.Context) {
    merchantID := utils.GetMerchantID(c) // 从JWT获取商家ID

    var stats struct {
        TotalUsers       int64   `json:"total_users"`       // 总用户数
        NewUsersToday    int64   `json:"new_users_today"`  // 今日新增用户
        NewUsersWeek     int64   `json:"new_users_week"`   // 本周新增用户
        NewUsersMonth    int64   `json:"new_users_month"`  // 本月新增用户
        PaidUsers        int64   `json:"paid_users"`       // 已支付用户数
        UnpaidUsers      int64   `json:"unpaid_users"`     // 未支付用户数
        TotalVisitCount  int64   `json:"total_visit_count"` // 总访问次数
        AvgVisitPerUser  float64 `json:"avg_visit_per_user"`// 人均访问次数
        ActiveUsers      int64   `json:"active_users"`      // 活跃用户（7天内访问）
    }

    today := time.Now().Format("2006-01-02")
    weekAgo := time.Now().AddDate(0, 0, -7).Format("2006-01-02")
    monthAgo := time.Now().AddDate(0, -1, 0).Format("2006-01-02")

    // 统计总用户数（按openid去重）
    database.DB.Model(&models.Order{}).
        Where("merchant_id = ?", merchantID).
        Count(&stats.TotalUsers)

    // 今日新增用户
    database.DB.Model(&models.Order{}).
        Where("merchant_id = ? AND DATE(first_visit_at) = ?", merchantID, today).
        Count(&stats.NewUsersToday)

    // 本周新增用户
    database.DB.Model(&models.User{}).
        Where("first_visit_at >= ?", weekAgo).
        Count(&stats.NewUsersWeek)

    // 本月新增用户
    database.DB.Model(&models.User{}).
        Where("first_visit_at >= ?", monthAgo).
        Count(&stats.NewUsersMonth)

    // 已支付用户数
    database.DB.Model(&models.User{}).
        Where("has_paid = ?", true).
        Count(&stats.PaidUsers)

    // 未支付用户数
    stats.UnpaidUsers = stats.TotalUsers - stats.PaidUsers

    // 总访问次数
    database.DB.Model(&models.UserVisit{}).
        Where("merchant_id = ?", merchantID).
        Count(&stats.TotalVisitCount)

    // 人均访问次数
    if stats.TotalUsers > 0 {
        stats.AvgVisitPerUser = float64(stats.TotalVisitCount) / float64(stats.TotalUsers)
    }

    // 活跃用户（7天内访问）
    database.DB.Model(&models.User{}).
        Where("last_visit_at >= ?", weekAgo).
        Count(&stats.ActiveUsers)

    response.Success(c, stats)
}
```

**代码实现**：
```typescript
import { useAuth } from './useAuth'

interface VisitParams {
  merchant_id: number
  source?: string // 来源：scan/share/search
}

export function useAnalytics() {
  const { getOpenid } = useAuth()

  const trackVisit = async (params: VisitParams) => {
    const openid = getOpenid()
    if (!openid) {
      console.log('Analytics: 用户未登录，跳过埋点')
      return
    }

    try {
      await uni.request({
        url: `http://localhost:8080/api/v1/store/${params.merchant_id}/visit`,
        method: 'POST',
        data: {
          openid,
          source: params.source || 'scan'
        }
      })
      console.log('Analytics: 访问埋点已记录', params)
    } catch (error) {
      console.error('Analytics: 埋点记录失败', error)
    }
  }

  return {
    trackVisit
  }
}
```

## 2.2.11 用户行为埋点与分析

### 功能描述
用户扫码进入商家主页时，系统自动记录用户访问行为，支持按 OpenID 去重统计用户数量、访问次数、支付转化等数据。

### 埋点事件
- **用户访问事件**：记录用户访问商家主页的时间、来源
- **数据去重**：通过 OpenID 唯一标识用户，同一用户多次访问只算一个
- **统计维度**：用户数、访问次数、支付转化、活跃度

### 数据统计
- **总用户数**：该商家累计吸引的用户总数（按 OpenID 去重）
- **新增用户**：今日/本周/本月新增用户数
- **已支付用户**：该商家内有支付记录的用户数
- **未支付用户**：有访问但未支付的用户数
- **总访问次数**：累计访问人次
- **人均访问次数**：总访问次数 / 总用户数
- **活跃用户**：7天内有访问的用户数

### 服务商视角

- 各商家用户数量对比
- 用户增长趋势

## ⚠️ 注意事项

1. **埋点性能**：埋点请求应为异步，不阻塞主流程
2. **数据准确性**：确保按 OpenID 去重，避免重复统计
3. **隐私合规**：埋点数据仅用于商家运营分析，不涉及用户敏感信息
4. **接口安全**：埋点接口可公开，但需要校验 OpenID 格式
5. **数据存储**：UserVisit 表会随时间增长，考虑定期归档
