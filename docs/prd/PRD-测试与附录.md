# PRD-测试与附录

## 1. 文档定位

本文件用于承接 `PRD.md` 中与"测试账号、验收口径、环境说明、部署注意事项、文档维护规则"相关的内容。

读取顺序：

1. 先读根目录 `PRD.md`
2. 再读本文件
3. 如需完整测试输出，可继续读独立测试报告或 `docs/prd/测试报告模板.md`

## 2. 测试账号与数据准备

### 2.1 默认最小初始化账号

- 商户管理员：`merchant / merchant123`
- 服务人员：`staff / staff123`

- Mock 数据应覆盖：
  - 商户

  - 订单
  - 用户
  - 服务人员

### 2.3 测试前准备

- 确认数据库初始化完成
- 确认后端服务可用
- 确认客户端小程序与服务人员接单小程序环境变量已配置

- 确认微信支付商户 V3 Key、平台公钥证书、公钥与回调地址已作为系统级配置注入
- 确认已回填商户子商户号可用于支付联调，例如 `1112649854`

## 3. 验收重点

### 3.1 商户PC后台端

- 能正常登录与退出
- 退出登录后 WebSocket 立即断开
- 能维护商品、分类、配送、设置
- 商户配送设置页可独立回显并保存 `takeout_enabled`、`dine_in_enabled`、`pickup_enabled`
- 能查看订单详情并完成核销
- 能对已支付 / 已完成订单发起退款
- 工作台今日概览中的待核销订单与已上架商品数口径正确
- 商户分析页库存预警看板支持空态与风险分组展示
- 商户订单列表支持快捷范围和自定义日期筛选
- 商户设置页以顶部信息卡和功能宫格展示高频入口
- 商户满减规则支持保存、回显、启停和最多 5 档限制
- 商户打印机支持新增、编辑、删除、状态开关、自动打印、默认打印机和测试打印
- 能管理服务人员（列表、新增、编辑、删除、审核注册申请）
- **租赁商品配置**：商品新增/编辑表单可切换销售类型为"租赁"，并填写计费周期、单位租金、押金、最大租赁时长；租赁商品保存后列表显示"租赁"标签与 `¥{rental_price}/{unit}` 价格
- **租赁订单归还**：已支付的租赁订单详情展示押金明细与"归还退押金"按钮；填写扣除金额和验机备注后调用归还接口，押金原路退还，押金状态更新为已退还/已扣除

### 3.2 用户端（客户端小程序）

- 能扫码进入商城首页
- 底部 tabBar 正常展示「首页、分类、购物车、我的」四个 tab，切换正常
- `pages/home/index`、`pages/store/product`、`pages/store/confirm` 统一解析店铺入口参数（单商户模式，入口固定单店）
- 首页轮播图正常展示与自动轮播，点击可跳转对应商品/分类
- 首页商品活动区域展示当前生效的满减规则摘要
- 首页服务分类图标宫格正常展示，点击跳转分类页对应分类
- 「我的」页面展示用户信息、我的订单入口、收货地址管理、联系商户
- 能自动登录并完成埋点
- 商城首页与确认订单页的公开数据请求不依赖先完成登录
- 确认订单页只展示商户已开启的配送 / 堂食 / 自提方式，未开启方式不展示
- 确认订单页可展示满减规则、已命中优惠和下一档提示
- 创建订单后的 `discount_amount`、`pay_amount` 与确认页展示口径一致
- 能浏览商品、加购、下单、支付
- 能查看订单并申请退款
- **租赁商品展示**：首页/分类列表中租赁商品显示"租赁"标签与单位租金价格，点击"+"跳详情页（不打开规格弹窗）
- **租赁商品详情**：商品详情页展示租金/押金、租赁时长选择器，并实时计算租金、押金与合计
- **租赁商品加购/立即购买**：加购和立即购买均携带 `rental_duration`，购物车与确认订单页正确展示租赁信息
- **租赁订单详情**：订单详情页展示租赁时长、押金、押金状态（含扣除/退还金额、归还时间与备注）

### 3.3 服务人员端（接单小程序）

- 能正常登录与退出
- 能查看待接订单列表
- 能执行接单操作，接单为原子操作
- 接单成功后订单写入 `accepted_by_staff_id` 与 `accepted_at`
- 能查看已接订单列表
- 能查看订单详情（商品明细、配送信息、支付信息）
- 能查看接单统计（今日与累计接单数量、金额）
- 能提交注册申请，提交后进入待审核状态
- 待接订单列表与已接订单列表均保证空数组兜底
- 服务人员无核销权限，核销由商户管理员在PC后台执行

### 3.4 支付

- 商户下单时能拉起对应的 `sub_mch_id`
- 未完成支付配置的商户会被下单拦截
- 使用 `1112649854` 的商户样例可正常拉起支付
- 下单请求 `sp_appid` 使用 `WECHAT_PAY_SP_APP_ID`、`sub_appid` 使用 `WECHAT_APP_ID`，支付人取 `payer.sub_openid`，不出现 `APPID_MCHID_NOT_MATCH`
- 支付回调后订单支付状态正确

## 4. 推荐测试链路

### 4.1 完整经营链路

1. 商户管理员登录PC后台
2. 创建商品与规格
3. 用户扫码进入商城首页
4. 商城首页、商品详情、确认订单按统一入口参数加载当前商户数据
5. 用户完成下单支付
6. PC后台收到 WebSocket 提醒
7. 服务人员接单
8. 商户管理员查看订单详情并核销
9. 商户查看经营分析数据

### 4.2 支付配置链路

1. 商户管理员在PC后台回填 `sub_mch_id`
2. 用户完成下单支付
3. 支付回调更新订单状态

### 4.3 服务人员接单链路

1. 服务人员提交注册申请
2. 商户管理员在PC后台审核通过
3. 服务人员登录接单小程序
4. 查看待接订单列表
5. 执行接单
6. 查看已接订单与接单统计

### 4.4 商品租赁链路

1. 商户管理员在 PC 后台新增租赁商品（配置计费周期、单位租金、押金、最大租赁时长）
2. 用户在首页/分类页看到租赁商品（带"租赁"标签与 `¥{rental_price}/{unit}` 价格）
3. 用户进入商品详情页选择租赁时长，加入购物车或立即购买
4. 用户在确认订单页看到押金明细与归还提示，提交订单并支付（租金 + 押金）
5. 用户在订单详情页查看租赁时长与押金状态
6. 商户管理员在 PC 后台订单详情点击"归还退押金"，填写扣除金额（可选）与验机备注
7. 系统原路退还押金，订单 `deposit_status` 更新为已退还/已扣除
8. 商户管理员核销订单，订单流转为 `completed`

### 4.5 文档链路

1. 先读 `PRD.md`
2. 再读功能说明
3. 再读接口文档
4. 最后读测试与附录

  - 商户管理员主动退出与 401 登录失效时的 WebSocket 断连收口
  - 用户支付成功后PC后台收到 `order_notify` 提醒
  - 订单号包含时间戳、商户ID和随机数
  - 确认页拉起支付时金额不归零，支付成功后再清空购物车
  - 商户设置页顶部信息卡与功能宫格入口展示
  - 商户满减规则的配置、回显、启停与最多 5 档限制
  - 确认订单页的满减规则展示、下一档提示与优惠金额展示
  - 打印机管理页的新增、编辑、状态开关、自动打印、默认打印机与测试打印
  - 订单详情"联系商户退款"点击后直接拨打商户电话
  - 商户配送设置页可独立控制配送、堂食、自提三个开关，并与 `takeout_enabled`、`dine_in_enabled`、`pickup_enabled` 一一对应
  - 确认页根据三字段动态展示可选下单方式，未开启方式不显示
  - `delivery_settings.enabled` 继续只承担配送费规则开关职责，不替代配送下单方式展示开关
  - 商户订单核销码直核与退款参数对齐
  - 商户数据分析新口径与空值兜底
  - 商户维护 Logo / 背景图
  - 商户维护支付配置
  - 服务人员注册申请与PC后台审核
  - 服务人员接单为原子操作，避免重复接单
  - 接单与核销分离，服务人员仅接单，商户管理员在PC后台核销
  - **商品租赁模式全栈验证**：
    - PC 后台商品配置 sale_type/rental_unit/rental_price/deposit/max_rental_duration，列表按销售类型筛选与展示
    - C 端首页/分类页对租赁商品的标签与价格展示
    - C 端商品详情页租赁时长选择与租金/押金实时计算
    - 购物车、确认订单页对租赁商品行金额（含押金）与合计的正确展示
    - 创建订单接口 `items[].rental_duration` 入参与 `total_deposit`/`pay_amount` 后端计算口径一致
    - 归还接口 `POST /api/v1/merchant/orders/{order_id}/return` 押金原路退还与状态回写
    - 订单详情页对租赁时长、押金状态、扣除/退还金额、归还时间与备注的展示

## 6. 部署与环境附录

### 6.1 小程序环境

- HTTP / WS 地址统一走环境配置
- 客户端小程序与服务人员接单小程序分别配置环境变量
- 生产环境需显式配置 `https://` 与 `wss://`

### 6.2 后端环境

- 推荐使用环境变量注入
- 生产环境关闭调试模式
- 敏感配置不落仓库
- 微信支付商户凭证作为系统级配置注入
