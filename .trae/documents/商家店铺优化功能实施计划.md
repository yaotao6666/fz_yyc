# 商家店铺优化功能实施计划

## 📋 需求概述

### 功能目标
1. **操作指引弹窗**：用户通过扫码进入店铺首页时，显示操作指引提示
2. **我的订单按钮**：在底部购物栏左侧添加「我的订单」快速入口
3. **商家订单筛选**：订单列表支持按商家筛选，仅显示当前商家的订单

### 用户需求确认
- ✅ 弹窗显示频率：每次进入都显示
- ✅ 弹窗内容：操作指引提示
- ✅ 按钮位置：底部购物栏左侧
- ✅ 订单列表：复用现有页面，筛选当前商家订单
- ✅ 登录验证：无需登录，使用微信 openid 识别用户

---

## 📊 当前状态分析

### 现有页面和组件
1. **`pages/store/home.vue`** - 店铺首页
   - 店铺头部信息展示
   - 分类和商品列表
   - 底部购物栏（有购物车按钮，无订单按钮）

2. **`pages/store/cart.vue`** - 购物车页面
   - 购物车商品列表
   - 结算功能

3. **`pages/store/my-orders.vue`** - 我的订单页面
   - 订单列表（按状态筛选）
   - 订单详情、取消、退款等功能
   - **当前不支持按商家筛选**

### API 接口现状
- **前端 API**：`getMyOrders(params)` - 不支持 merchant_id 参数
- **后端 API**：`GET /api/v1/user/orders` - 不支持 merchant_id 参数

#### 1.2 修改订单列表页面 `pages/store/my-orders.vue`
**文件路径**：`miniprogram/src/pages/store/my-orders.vue`

**修改内容**：
1. **接收 merchant_id 参数**
2. **筛选当前商家的订单**
3. **显示当前商家信息**

**具体修改**：
```typescript
onShow(() => {
  const pages = getCurrentPages()
  const currentPage = pages[pages.length - 1] as any
  const merchantId = Number(currentPage?.options?.merchant_id) || 0

  if (merchantId > 0) {
    loadOrders(merchantId)
  } else {
    loadOrders() // 加载全部订单
  }
})

async function loadOrders(merchantId?: number) {
  const params: any = {
    page: page.value,
    page_size: pageSize
  }

  if (currentStatus.value > 0) {
    params.status = currentStatus.value
  }

  // 如果传入了 merchant_id，需要在前端过滤或后端支持
  if (merchantId) {
    params.merchant_id = merchantId
  }

  // 调用 API
  const res = await getMyOrders(params)

  if (merchantId) {
    // 按商家过滤订单
    orders.value = res.list.filter(order => order.merchant_id === merchantId)
  } else {
    orders.value = res.list
  }
}
```

  page_size?: number
  status?: number
