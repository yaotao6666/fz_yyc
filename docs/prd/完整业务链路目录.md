# 完整业务链路目录

## 1. 文档定位

本文件用于按角色梳理完整业务链路，方便研发、测试、产品和大模型按顺序理解系统主流程。

## 2. 商户经营链路（PC后台）

1. 商户管理员登录PC后台
2. 店铺资料维护
3. 分类与商品配置
4. 配送与营业状态设置
5. 服务人员管理（后台添加+注册审核）
6. 接收订单提醒
7. 查看订单详情
8. 核销订单
9. 处理退款
10. 查看经营分析

## 3. 用户下单链路（客户端小程序）

1. 扫码进入商城首页（tabBar 导航）
2. 自动登录与埋点
3. 浏览轮播图、商品活动、分类图标宫格
4. 切换分类 tab 或首页点击商品浏览
5. 选择规格与数量
6. 加入购物车
7. 切换 tabBar 到购物车结算
8. 提交订单
9. 微信支付
10. 查看订单
11. 申请退款

## 4. 服务人员接单链路（接单小程序）

1. 服务人员登录接单小程序
2. 查看待接订单列表
3. 接单（写入 `accepted_by_staff_id` 与 `accepted_at`）
4. 查看已接订单列表
5. 查看订单详情
6. 查看接单统计

## 5. 支付回调链路

1. 微信支付回调进入服务端
2. 校验签名并解密回调报文
3. 更新订单支付状态与交易单号
4. 向PC后台推送 `order_notify`
5. 向服务人员小程序推送待接订单提醒

## 6. 验证建议

- 每次完整回归至少覆盖：
  - 商户经营链路（PC后台）
  - 用户下单链路（客户端小程序）
  - 服务人员接单链路（接单小程序）
  - 支付回调链路
