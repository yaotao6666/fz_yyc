# 客户端小程序商城化升级计划

## 1. 摘要

将客户端小程序从「扫码直达单店铺首页」模式升级为「单商户商城」模式，新增底部 tabBar 导航（首页、分类、购物车、我的），首页增加轮播图、商品活动、服务分类图标宫格等模块。本次改造范围为 **PRD 文档更新**，不涉及实际代码实现。

## 2. 当前状态分析

### 2.1 客户端小程序现状

- **无 tabBar**：通过扫描商户二维码直达 `pages/store/home`，无底部导航
- **页面结构**：全部 10 个页面位于 `pages/store/` 下（home、product、cart、confirm、my-orders、order-detail、address-list、address-edit、test-entry、order-sound-test）
- **首页布局**：店铺头部横幅 → 吸顶迷你头部 → 我的订单快捷入口 → 左侧分类侧边栏 + 右侧商品列表 → 底部购物车结算栏 → 加购弹窗 → 操作指引弹窗
- **API**：`GET /api/v1/store/{merchant_id}/home` 返回 `merchant` + `categories` + `hot_products`
- **分类表**：`categories` 表仅有 `id/merchant_id/name/sort/status`，无 icon 字段
- **无轮播图**：PRD 和代码中均无 banner/轮播相关定义
- **无独立「我的」页面**：用户订单入口仅在首页快捷卡片

## 3. 目标架构定义

### 3.1 新页面结构与 tabBar

```
tabBar:
├── 首页 (pages/home/index)        — 轮播图 + 活动入口 + 分类图标宫格 + 热销商品
├── 分类 (pages/category/index)    — 全部分类列表 + 分类下商品浏览
├── 购物车 (pages/cart/index)      — 购物车商品管理 + 去结算
└── 我的 (pages/my/index)          — 用户信息 + 我的订单 + 收货地址 + 联系商户
```

### 3.2 首页模块布局（从上到下）

1. **顶部搜索栏**（可选）：店铺名称 + 搜索入口
2. **轮播图**：商户配置的 banner 图片，自动轮播，可配置跳转链接
3. **服务分类图标宫格**：商品分类以 icon 图标形式展示，点击跳转分类页对应分类
4. **商品活动区域**：展示当前生效的满减规则、优惠活动信息
5. **热销推荐 / 商品列表**：热门商品或全部分类商品流

### 3.3 新增数据模型

#### 轮播图表 (banners)

| 字段 | 类型 | 描述 |
|------|------|------|
| id | BIGINT | 主键 |
| merchant_id | BIGINT | 商户ID |
| image | VARCHAR(512) | 轮播图片URL |
| link_type | VARCHAR(32) | 跳转类型：product/category/none |
| link_value | VARCHAR(128) | 跳转目标值（商品ID/分类ID） |
| sort | INT | 排序权重 |
| status | TINYINT | 状态：0禁用 1启用 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

#### 分类表补充字段

在 `categories` 表新增：
- `icon` VARCHAR(512) — 分类图标URL

## 5. 假设与决策

1. **交付范围**：仅更新 PRD 文档，不实现实际代码
2. **tabBar 四页**：首页（轮播+活动+分类图标+热销）、分类（全分类+商品列表）、购物车（商品管理+结算）、我的（用户信息+订单+地址+联系商户）
3. **轮播图管理**：由商户在 PC 后台配置，新增 `banners` 表
4. **分类图标**：在 `categories` 表新增 `icon` 字段，由商户在 PC 后台分类管理中上传
5. **商品活动**：复用现有满减规则（`full-reduction-rules`），首页展示活动摘要
6. **扫码入口保留**：扫码仍为进入商城的方式，二维码指向 `pages/home/index`
7. **现有页面保留**：商品详情、确认订单、我的订单、订单详情、地址管理等非 tabBar 页面保留在 `pages/store/` 下
8. **「我的」页面内容**：用户头像昵称 + 我的订单入口 + 收货地址管理 + 联系商户电话
