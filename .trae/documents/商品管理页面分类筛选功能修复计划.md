# 商品管理页面分类筛选功能修复计划

## 📋 需求概述

### 问题描述
商家管理端的商品管理页面（`pages/merchant/products/list.vue`）缺少分类筛选功能，导致商家无法按分类查看商品。

### 功能目标
在商品管理页面左侧添加分类筛选功能，支持商家按分类查看商品列表。

---

## 📊 当前状态分析

### 现有功能
1. **搜索功能**：支持按商品名称搜索
2. **状态筛选**：支持按上架/下架状态筛选
3. **批量操作**：支持批量上架、下架

### 已有接口
1. **后端接口**：`GET /api/v1/merchant/products`
   - 已支持 `category_id` 参数（第178行）
   - 已支持 `status`、`keyword` 参数

2. **前端API**：`getProducts(params)`
   - 已支持 `category_id` 参数（第202行）
   - 位于 `miniprogram/src/api/index.ts` 第199-207行

3. **分类接口**：`getCategories()`
   - 用于获取商家分类列表
   - 位于 `miniprogram/src/api/index.ts` 第162-164行

### 缺失部分
- 前端页面缺少分类选择器UI
- 未加载分类列表数据
- 查询商品时未传递 `category_id` 参数

---

## 🎯 实施计划

### 方案设计

#### UI布局
在现有筛选栏的左侧添加分类选择器，布局如下：

```
┌─────────────────────────────────────────────────┐
│ [分类选择器▼]  [搜索框] [搜索按钮]              │
│ [全部] [上架] [下架]                             │
└─────────────────────────────────────────────────┘
```

#### 交互逻辑
1. 页面加载时自动获取分类列表
2. 点击分类选择器显示分类列表
3. 选择分类后自动刷新商品列表
4. 分类筛选与状态筛选、搜索可组合使用

#### 2. 脚本修改（第112-191行）

**新增导入**：
```typescript
import { getProducts, getCategories, productOnSale, productOffSale, deleteProduct as deleteProductApi, batchUpdateProductStatus } from '@api'
import type { Product, Category } from '@types'
```

**新增响应式数据**（第118行后）：
```typescript
const categories = ref<Category[]>([])
const selectedCategoryId = ref<number | null>(null)
const selectedCategoryIndex = ref(0)

const categoryOptions = computed(() => {
  return [
    { id: null, name: '全部分类' },
    ...categories.value.map(c => ({ id: c.id, name: c.name }))
  ]
})

const selectedCategoryLabel = computed(() => {
  return categoryOptions.value[selectedCategoryIndex.value]?.name || '全部分类'
})
```

**新增加载分类函数**：
```typescript
async function loadCategories() {
  try {
    const data = await getCategories()
    categories.value = data || []
  } catch (error) {
    console.error('加载分类失败:', error)
    categories.value = []
  }
}
```

**修改 onShow**（第131-133行）：
```typescript
onShow(() => {
  loadCategories()
  loadProducts(true)
})
```

**修改 loadProducts 函数**（第147-159行）：
```typescript
const params: any = {
  page: page.value,
  page_size: pageSize,
}

if (selectedCategoryId.value !== null) {
  params.category_id = selectedCategoryId.value
}

if (filterStatus.value) {
  params.status = filterStatus.value === 'on_sale' ? 1 : 2
}

if (keyword.value) {
  params.keyword = keyword.value
}
```

**新增分类选择处理函数**：
```typescript
function onCategoryChange(e: any) {
  const index = e.detail.value
  selectedCategoryIndex.value = index
  selectedCategoryId.value = categoryOptions.value[index]?.id || null
  loadProducts(true)
}
```
